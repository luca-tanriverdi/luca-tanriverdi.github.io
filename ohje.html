Miten käyttää Windows Defender -virustorjuntaa

Windows Defender on Microsoftin virallinen virustorjuntaohjelma, joka on integroitu kaikkiin
Windows-käyttöjärjestelmiin. Tämän käyttöohjeen avulla opit käyttämään Windows Defenderiä.

Automaattinen tarkistus

  1. Avaa Windows Defender -sovellus
  2. Tarkista mahdolliset uhat "Virusten ja uhkien torjunta" -osiosta

Manuaalinen tarkistus

  1. Avaa Windows Defender -sovellus
  2. Valitse "Virusten ja uhkien torjunta" ja suorita tarpeesi mukaan:
    • Pikatarkistus
    • Perusteellinen tarkistus
    • Mukautettu tarkistus
    • Offline tarkistus

Version tarkistaminen

  1. Avaa Windows Defender -sovellus
  2. Valitse "Asetukset" ruudun vasemmasta alareunasta
  3. Tarkista ohjelman versio painamalla "Tietoja"
